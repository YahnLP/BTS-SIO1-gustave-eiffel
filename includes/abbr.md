*[NUMA]: Accès mémoire non uniforme : Dans un serveur à deux processeurs, chacun accède plus vite à sa propre mémoire qu'à celle de l'autre.
*[SLA]: Accord de niveau de service : Engagement écrit sur la qualité d'un service (délais de prise en charge et de résolution, disponibilité).
*[OLA]: Accord de niveau opérationnel : Engagement entre équipes d'une même organisation.
*[IP]: Adresse IP : Numéro qui identifie une machine sur un réseau (exemple : 192.168.1.20). Voir la fiche « minimum réseau ».
*[AD]: Annuaire de Microsoft : Annuaire utilisé dans les entreprises Windows. Notion technique.
*[OVA]: Appliance virtuelle : Fichier unique contenant une machine virtuelle toute prête, à importer.
*[DHCP]: Attribution automatique d'adresses : Service qui donne automatiquement une adresse IP aux machines qui se connectent. Vu en cours de réseau.
*[CMDB]: Base de gestion des configurations : Base de données qui décrit les éléments du parc et les liens entre eux.
*[ITIL]: Bibliothèque d'infrastructure des technologies de l'information : Ensemble de bonnes pratiques pour organiser un service informatique.
*[PCIe]: Bus d'extension PCIe : Bus rapide pour brancher des cartes (graphique, réseau) et des SSD NVMe.
*[GPU]: Carte graphique : Composant spécialisé dans le calcul d'images.
*[CNIL]: Commission nationale de l'informatique et des libertés : Autorité française qui contrôle l'application du RGPD.
*[SSH]: Connexion sécurisée à distance : Prendre le contrôle d'un terminal sur une autre machine, par une connexion chiffrée.
*[UAC]: Contrôle de compte d'utilisateur : Fenêtre de Windows qui demande une confirmation avant une action d'administrateur.
*[PXE]: Démarrage par le réseau : Une machine démarre en allant chercher son système sur le réseau au lieu d'un disque.
*[HDD]: Disque dur : Stockage à plateaux tournants : grand, peu cher, assez lent.
*[SSD]: Disque SSD : Stockage sans pièce mobile (mémoire flash) : plus rapide et plus résistant aux chocs qu'un disque dur.
*[RTO]: Durée maximale d'interruption admise : Le temps maximum acceptable pour remettre le service en marche après une panne.
*[CI]: Élément de configuration : Un élément décrit dans la CMDB : poste, serveur, logiciel, service.
*[YAML]: Fichier de configuration YAML : Format de texte où l'on décrit une configuration avec des retraits. Notion technique.
*[GLPI]: Gestion libre de parc informatique : Logiciel libre de gestion de parc et d'assistance (tickets).
*[GHz]: Gigahertz : Un milliard de cycles par seconde.
*[RAID]: Grappe de disques : Plusieurs disques utilisés ensemble pour gagner en vitesse et/ou résister à la panne d'un disque. Ce n'est pas une sauvegarde.
*[ISO]: Image disque ISO : Un fichier qui contient le contenu d'un DVD d'installation.
*[WMI]: Interface de gestion Windows : Façon d'interroger à distance un poste Windows. Notion technique.
*[NVMe]: Interface de stockage NVMe : Connexion rapide pour SSD, branchée directement sur le bus PCIe.
*[SATA]: Interface de stockage SATA : Type de connexion classique entre un disque et la carte mère.
*[GUI]: Interface graphique : On commande avec la souris, des fenêtres et des icônes.
*[GPL]: Licence publique générale : Licence libre qui impose de redistribuer sous la même licence les versions modifiées.
*[CLI]: Ligne de commande : On commande en tapant du texte dans un terminal.
*[VM]: Machine virtuelle : Un ordinateur simulé par un logiciel, qui tourne dans une fenêtre de l'ordinateur réel.
*[ECC]: Mémoire à correction d'erreurs : Mémoire de serveur qui détecte et corrige certaines erreurs.
*[RAM]: Mémoire vive : Mémoire rapide où l'ordinateur place ce qu'il utilise en ce moment ; elle se vide quand on éteint.
*[BIOS]: Micrologiciel de démarrage : Programme inscrit sur la carte mère qui démarre la machine avant le système ; ancienne génération.
*[UEFI]: Micrologiciel de démarrage moderne : Remplaçant moderne du BIOS : démarrage plus rapide, disques de grande taille, démarrage sécurisé.
*[TPM]: Module de plateforme de confiance : Puce de sécurité qui stocke des clés de chiffrement ; exigée par Windows 11.
*[RPO]: Perte de données maximale admise : La quantité de données (exprimée en temps) que l'on accepte de perdre.
*[PCA]: Plan de continuité d'activité : Organisation qui permet à l'activité de continuer malgré un sinistre. Notion technique.
*[PRA]: Plan de reprise d'activité : Organisation qui permet de relancer l'activité après un sinistre. Notion technique.
*[CPU]: Processeur : Le composant qui exécute les instructions des programmes.
*[LDAP]: Protocole d'annuaire : Langage pour interroger un annuaire. Notion technique.
*[TCP/IP]: Protocole de communication réseau : L'ensemble de règles de communication utilisé par Internet. Vu en cours de réseau.
*[SNMP]: Protocole de supervision réseau : Permet d'interroger à distance un équipement réseau (imprimante, commutateur) sur son état.
*[RGPD]: Règlement général sur la protection des données : Loi européenne qui protège les données personnelles.
*[GPO]: Stratégie de groupe : Règles appliquées automatiquement aux comptes et aux postes Windows d'un domaine. Notion technique.
*[GPT]: Table de partition GPT : Façon moderne d'organiser un disque, utilisée avec l'UEFI : disques très grands, nombreuses partitions.
*[MBR]: Table de partition MBR : Ancienne façon d'organiser un disque : limitée à 2 To et 4 partitions principales.
*[MTTR]: Temps moyen de résolution : Durée moyenne pour réparer une panne.
*[NAT]: Traduction d'adresses : Le routeur ou l'hôte fait passer les machines du réseau privé sur Internet avec sa propre adresse. Vu en cours de réseau.
