## Windows → Linux (à vérifier en S08)

| Je veux… | Windows | Linux (à tester) |
|---|---|---|
| Voir où je suis | `cd` | `pwd` |
| Lister | `dir` | `ls` |
| Voir les processus | `tasklist` | `ps aux` |
| Voir mon adresse IP | `ipconfig` | `ip a` |
| Voir l'espace disque | Gestion des disques | `df -h` |
| Voir la mémoire | Gestionnaire des tâches | `free -h` |
| Voir la version du système | `winver` | `cat /etc/os-release` |
| Voir qui je suis | `whoami` | `whoami` |

## Choisir un système : critères

coût total · compétences disponibles · compatibilité des logiciels métier · sécurité · durée du support · matériel · administration à distance · automatisation
