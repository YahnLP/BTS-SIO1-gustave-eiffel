# L'IA dans le métier : repères

Chaque TP se termine par une courte rubrique « L'IA dans ce métier ». Ces repères communs servent de socle.

## Ce que l'IA peut faire pour un technicien

- **Expliquer** un message d'erreur ou une commande, proposer des pistes de diagnostic.
- **Rédiger** un premier jet (réponse à un utilisateur, procédure, compte rendu) que tu relis et corriges.
- **Générer** un squelette de script ou de configuration que tu vas lire ligne par ligne.
- **Résumer** une documentation longue, **reformuler** un texte pour un public non technique.

## Ce qu'elle ne remplace pas

- Elle peut **se tromper avec aplomb** : une commande inventée, une option qui n'existe pas. Toute réponse se **teste** sur une machine de test avant la production.
- Elle ne connaît pas **ton** parc ni **ton** contexte.

## Règles à respecter

1. **Aucune donnée confidentielle** dans un outil d'IA externe : pas de mot de passe, pas d'adresse interne réelle, pas de nom d'utilisateur, pas de données personnelles (RGPD). Anonymise.
2. Respecte la **politique de ton entreprise** : certaines interdisent ces outils.
3. **Cite** ton usage quand le rendu l'exige, et reste capable d'**expliquer** ce que tu rends.
4. **Vérifie** dans la documentation officielle.
