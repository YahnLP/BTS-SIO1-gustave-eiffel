# Tableau de synthèse des réalisations

Pour l'épreuve E5 (support et mise à disposition de services informatiques), le portfolio est accompagné d'un **tableau de synthèse** (annexe VI-1) : pour **chaque réalisation**, les compétences du bloc 1 mobilisées, un **intitulé court**, la liste des **productions et documents associés** et la **période**. Un modèle `.xlsx` est fourni avec la circulaire nationale : utilise-le pour le rendu final. Son absence est pénalisée.

| N° | Intitulé court | Période | Compétences du bloc 1 | Productions et documents |
|---|---|---|---|---|
| R1 | Inventaire du parc et GLPI | oct.–déc. | B1.1 | Fiche d'inventaire, captures GLPI, compte rendu |
| R2 | Traitement de tickets | jan.–fév. | B1.2 | 2 tickets rédigés, compte rendu à l'utilisateur |
| R3 | … | | | |

Conseils :

- Une ligne par réalisation, pas par TP.
- Une réalisation peut mobiliser plusieurs compétences ; l'ensemble doit **couvrir** le bloc.
- Chaque production citée doit être **accessible** dans ton portfolio (un portfolio inaccessible est sévèrement pénalisé).
- Les attestations de stage ou certificats de travail complètent le dossier.
