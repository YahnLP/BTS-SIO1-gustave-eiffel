# Semestre 2 (SR1) – Conteneurs, gestion de parc, ITIL et services

**Objectif du semestre :** gérer le patrimoine informatique, organiser le support selon ITIL et mettre à disposition des services (déploiement, automatisation, sauvegardes).

> [!NOTE]
> Les onze séances du semestre sont publiées. Elles s'appuient sur les simulateurs de l'auteur ([DockerLab](https://yahnlp.github.io/DockerLab/), [InfraLab](https://yahnlp.github.io/InfraLab/)) et sur des outils réels (GLPI, FOG). Les commandes et les écrans des outils réels sont à **tester en salle** avant chaque séance (voir les notes de l'enseignant et les corrigés).
