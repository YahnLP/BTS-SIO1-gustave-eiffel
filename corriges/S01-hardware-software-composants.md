## Questionnaire de positionnement

Sert à repérer : les étudiants qui ont déjà ouvert une machine, installé un système, utilisé un terminal ou une VM ; les inquiétudes. Pas de note. À relire à la fin du semestre pour mesurer la progression.

## Partie A

- Aucune réponse unique : la fiche dépend de la machine. Vérifier que chaque ligne est étayée par une étiquette lue ou une photo.
- Erreur fréquente : prendre le ventirad pour le processeur. Le processeur est dessous.
- Point d'attention : dans une machine récente, le SSD peut être une petite carte M.2 sous une plaque, pas un « boîtier » ; dans une machine de marque, la carte mère peut être non standard.
